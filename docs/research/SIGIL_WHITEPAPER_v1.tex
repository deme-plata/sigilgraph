\begin{abstract}
\noindent
SIGIL is an experimental DagKnight chain built on the Flux compiler-as-platform, sister
network to Quillon Graph. Where the v0 whitepaper described SIGIL layer by layer, this
edition opens the way its own physics appendix always demanded: with \emph{one equation}.
SIGIL's BlockDAG braid is modeled as a Lorentzian 4-manifold whose dynamics follow a single
variational principle, $\delta\SSIGIL=0$. Every protocol component — settlement conservation,
the PID emission controller, witness attestation, fork topology, and the post-quantum
cryptographic floor — drops out of that action as a field equation. Unlike most
physics-flavored chain papers, SIGIL's physics programme is \emph{falsifiable and partially
falsified-forward}: since v0 the network has produced a measured closed-form gossip delivery
law $D(p,r)=1-p^{r}$ (RMS residual $0.4$\,pp against 22 seeded simulations), a
constant-size whole-chain verification proof ($2{,}568$\,B regardless of chain length,
$342$\,ms at $100$k blocks), byte-identical multi-producer braid convergence
(divergence $=0$ across adversarial simulation gates), and live browser-class tip
verification in $3\,\mu$s — beating the founding 10\,ms claim by three orders of magnitude.
The chain runs live on network \texttt{sigil-g0} at height $\sim$29M with its 21M supply
fully minted. This paper presents the action, its field equations, the measured laws, the
architecture that implements them, and an unusually honest account of what remains
conjecture.
\end{abstract}

\section{Introduction: why a chain needs an action}

Quillon Graph, SIGIL's production sibling, was motivated by a concrete failure: in May 2026
a replay bug silently dropped a user wallet from 3200 to 1484 QUG, and \emph{no protocol
layer noticed}, because Quillon block headers commit only \texttt{(parent, tx\_merkle,
miner)}. There is no structural statement of what the network agrees the state \emph{is}.

SIGIL's founding move was to make agreement structural: four state roots in every header,
a provenance proof binding each block to the binary that produced it, and tip verification
cheap enough to run in a browser frame. The v0 whitepaper (2026-05-29) stated these as
three engineering claims. What v0 lacked — and what Quillon's own quantum-physics
whitepaper demonstrated the value of — is a \emph{unifying theoretical object} from which
the design follows, rather than a list of mechanisms.

That object exists. It was derived in the SIGIL master-equation programme
(2026-05-30/31) using the \texttt{flux-science} modules already in the workspace, and this
edition finally puts it where it was always intended:\ first.

Three cultural commitments carry over from v0 and bind everything below:

\begin{enumerate}[leftmargin=1.4em,itemsep=1pt]
\item \textbf{Measure the live path first.} A microbenchmark reading millions/s next to a
live number in hundreds/s \emph{is} the bug. Claims in this paper are tagged
\measured{measured} (a live or simulation-gated number exists) or
\pretend{conjecture} (theory ahead of data).
\item \textbf{Provenance is not optional.} Every release binary carries an SQIsign
Level-5 \texttt{.proof} emitted by the compiler itself.
\item \textbf{Honesty sections are load-bearing.} Every physics analogy and every
engineering claim gets a ``what's still pretend'' entry (\S\ref{sec:honesty}).
\end{enumerate}

\subsection{Field equations are protocol components}

Each variation of $\SSIGIL$ with respect to one field yields one subsystem of the running
chain. This is the paper's central organizational claim: \emph{SIGIL is not a stack of
mechanisms that happen to coexist; it is one action, varied six ways.}

\paragraph{$\delta\SSIGIL/\delta J^\mu = 0$ — conservation (the ledger).}
\begin{equation}
\nabla_\mu J^\mu = 0 \quad\Longleftrightarrow\quad
\partial_t \rho_{\mathrm{value}} + \nabla\!\cdot\!\mathbf{J}_{\mathrm{settle}}
= S_{\mathrm{emission}}(\varphi)
\end{equation}
Value is neither created nor destroyed except by the emission source term. In code this is
the \texttt{commit\_state\_transition} chokepoint (\S\ref{sec:state}): the \emph{only}
function permitted to mutate chain state, with conservation checked per typed delta.
The 21M supply cap is the integral form; the live network reads
\measured{21{,}000{,}000\,/\,21{,}000{,}000 SIGIL minted (100.0000\%)}.

\paragraph{$\delta\SSIGIL/\delta\varphi = 0$ — Klein–Gordon emission (monetary policy).}
\begin{equation}
\ddot{\varphi} + 3H\dot{\varphi} + V'(\varphi) = 0,\qquad
V(\varphi) = K_p\,e^2 + K_i\,e\!\!\int\! e\,dt + K_d\,(\dot e)^2
\end{equation}
The PID emission controller \emph{is} a scalar field rolling in a potential; the Hubble
friction term $3H\dot\varphi$ is network expansion (new blocks arriving). Inflationary
cosmology becomes economic policy. Stability prediction: the controller is
non-oscillatory iff $K_d^2 > 4K_pK_i$ (\S\ref{sec:predictions}).

\paragraph{$\delta\SSIGIL/\delta K = 0$ — topological invariance (fork detection).}
\begin{equation}
\frac{d}{dt}\,V_K(q)\Big|_{\mathrm{consensus}} = 0,\qquad K \in \pi_1(\mathcal{G})
\end{equation}
Valid consensus moves are Reidemeister moves on the braid; invariants are conserved. A
fork is a topology change and is detectable as one. \textbf{Computational honesty:} the
Jones polynomial is \#P-hard in general — nobody runs ``Jones consensus at 10k blocks/s.''
SIGIL's tractable programme (QTFT lanes) commits a \emph{cheap} invariant per block over a
bounded window — linking number ($O(\mathrm{crossings})$) or the Alexander polynomial
(polynomial-time via the Burau determinant) — reserving Jones/Khovanov machinery for rare
deep-fork adjudication off the hot path. The braid ordering layer this attaches to is
\measured{live}: the DagKnight braid shipped to the production node 2026-07-02
(\S\ref{sec:dagknight}).

\paragraph{$\delta\SSIGIL/\delta A^\mu = 0$ — Yang–Mills witnesses (divergence detection).}
\begin{equation}
\nabla_\nu F^{\mu\nu} = J^\mu_{\mathrm{witness}},\qquad F = dA + A\wedge A
\end{equation}
When two state-root tracks diverge, the curvature $F$ becomes locally non-zero; divergence
detection is the measurement of $|F|$ above threshold, and healing is the gauge
transformation restoring a flat connection. In code: four state roots per header, computed
independently by every node, with mismatch $\Rightarrow$ self-halt (exit code 78, no
auto-restart). The adversarial simulation gate measured \measured{divergence $=0$} across
all six scenarios (\S\ref{sec:dagknight}) — the flat-connection condition holds on the
paths tested.

The action admits a true extremum iff verification keeps pace with state transition:
$\Gamma_{\mathrm{verify}} \ge \Gamma_{\mathrm{state}}$. At the 2026-05-30 measurement the
ratio was $\sim$1840:1 against verification — a constrained saddle. The resolution came
exactly where the crypto term predicted: not faster per-signature verification but a
change of $\Sigma_{\mathrm{hash}}$ collapsing whole-chain verification to $O(1)$
(\S\ref{sec:fold}). \emph{The wall was a cryptographic choice, not a hardware limit} —
and it moved.

\section{Measured laws}\label{sec:measured}

This section is what distinguishes SIGIL's physics programme from decoration: closed-form
laws with residuals, gates with pass/fail, and live numbers.

\subsection{The gossip delivery law}\label{sec:delivery}

For a block gossiped with redundancy $r$ under independent per-transmission loss
probability $p$, the probability a node receives it at least once is

\begin{equation}
\boxed{\,D(p,r) = 1 - p^{\,r}\,}
\qquad\text{inverted to the provisioning rule}\qquad
r^{*} = \left\lceil \frac{\ln(1-\mathrm{SLA})}{\ln p} \right\rceil
\end{equation}

Derived and validated against \measured{22 seeded flux-chronos star-flood simulations;
RMS residual 0.4 percentage points}. The shipped default $r=3$ satisfies a 99.9\% SLA up
to $p=0.1$. This is statistical mechanics of the gossip layer done properly: model,
measurement, closed form, residual, and a provisioning rule operators actually use.
(Standalone paper: \emph{A Closed-Form Delivery Law for Gossip Redundancy in the sigil-top
Light Node}, published at \texttt{quillon.xyz/downloads/sigil-top-delivery-law.pdf}.)

\subsection{The fold: succinct whole-chain verification}\label{sec:fold}

The $\Sigma_{\mathrm{hash}}$ leg materialized as \texttt{flux-fold}: an Ajtai/SIS-based
folding scheme (post-quantum, no trusted setup) that compresses verification of the entire
chain prefix into one constant-size check:

The founding claim was tip verification in $\le$10\,ms in a browser. The live light node

three orders of magnitude, and the verification wall of \S\ref{sec:action} ceased to be
the binding constraint.

\subsection{DagKnight braid convergence}\label{sec:dagknight}

The braid ordering layer (\texttt{sigil-dagknight} + \texttt{flux-topology}) passed a
six-scenario adversarial simulation gate before production:

\begin{itemize}[leftmargin=1.4em,itemsep=0pt]
\item S1: 10k blocks / 3 producers, dual-instance — \measured{divergence $=0$}
\item S5: 30\% drop / reorder / equivocation — \measured{divergence $=0$}
\item Orderings: 16/16 permutations agree; incremental $\equiv$ batch
\item Withheld-block attacker: finalized prefix \measured{byte-identical (1378 blocks)}
\item Tamper suite: \measured{5/5 rejected}
\item S6: 100k blocks, max reorg window 258 $\le$ 16384 bound

A two-producer live mesh ran \measured{3385 emissions byte-identical} before the
production node flipped to the braid binary at height 17.52M (2026-07-02). In the language
of \S\ref{sec:action}: on every path tested, the topological invariants were conserved and
the witness curvature stayed flat.

\subsection{The sync ladder and the honest bottleneck}\label{sec:sync}

The throughput programme is a case study in the ``measure the live path first'' rule.
Local pipeline stages benchmark at 251k--2.5M blocks/s and a flat append-only skeleton
store (72\,B/record, two-phase durable, torn-tail safe) sustains \measured{$\sim$10M
records/s durable} — $2600\times$ the general-purpose LSM write path
($\sim$130\,$\mu$s/KV $\approx$ 3.9k blocks/s). An in-process end-to-end harness (pull
$\to$ stream-verify $\to$ commit at 2M records, roots matching) reaches \measured{39k
blocks/s}. And yet the live sync number stayed at $\sim$800 blocks/s for five days —
because the actual caps were a producer-side full-block serve throttle
($\le$1 per 120\,ms) and a serial request$\to$await$\to$apply fetch loop. The local
pipeline was \emph{never the wall}. The lesson is now Rule 0 of the SIGIL skill and a
methodological claim of this paper: \textbf{a fast microbenchmark next to a slow live
number is a bug report about your understanding, not a victory}. Wire compression is
measured at \measured{14.0$\times$ (zstd backfill codec, 70.7\,B/header live)} and
\measured{26.3$\times$ (gossip frames)}.

client key, and verifies the DNS tip anchor: an SQIsign-L5-signed \texttt{v=sigil1} TXT
record at the apex, so a fresh node can authenticate the tip before speaking to any peer.

\subsection{Dual-lane mining: $\Phi$ POWER $\times$ $\Omega$ TIME}\label{sec:mining}

A valid share carries \emph{both} lanes: $\Phi$ — BLAKE4 proof-of-work, and $\Omega$ — a
Wesolowski VDF proof of elapsed sequential time. BLAKE4 is a real primitive, not
branding: the BLAKE3 compression function with the round count parameterized; $R=7$ is
KAT-verified byte-identical to BLAKE3, $R<7$ is a measured speed lever ($2.9\times$ at
$R=1$, scalar). Consensus stays at $R=7$ until a reduced round count is cryptanalytically
validated. The TUI miner and the node share one verification function and one
cap-enforced crediting chokepoint; the loop is proven live (first credited shares
0\,$\to$\,1250 on \texttt{sigil-g0}).

\section{Honest status}\label{sec:honesty}

\subsection{What's real (with evidence)}

Live braid ordering on the production node; four state roots computed and committed
(wallet root live and non-trivial; DEX/event/contract roots currently zero pending those
subsystems' mainnet activation); fold tip verification at 3\,$\mu$s on the real chain;
dual-lane mining credited live; delivery-law-provisioned gossip; zstd wire compression
live at 70.7\,B/header; skeleton store and snapshot-pull code landed and
harness-proven; ML-KEM-1024 browser transport proven; SQIsign-signed releases and DNS tip
anchor operational; 21M supply minted with conservation enforced at the chokepoint.

\subsection{What's still pretend (physics)}

The reputation-induced metric $g_{\mu\nu}$ is a heuristic, not a derivation — the
functional form awaits fitting to measured consensus drift. Jones-polynomial machinery is
\#P-hard; only the bounded-window linking-number/Alexander programme is claimed tractable,
and the header topology commitment is staged, not shipped. AdS/CFT on a discrete graph is
an analogy pending rigorous discretization. The PID/Klein–Gordon mapping is exact only
for quadratic potentials; anti-windup and gain scheduling break integrability and are
deferred to higher-order correction terms. The ``product of three hardness assumptions''
security claim states design intent; a joint security model with a formal composition
bound is open work.

\subsection{What's still pretend (engineering)}

Snapshot-pull live activation awaits a pinned signed anchor on the fleet default;
until then nodes fall through to the compatible crawl path. The 2026-06-10 security audit
found the RPC money routes unauthenticated on the lab deployment (\texttt{sigil-oauth}
built, unwired) — acceptable for an experimental network whose value is explicitly
laboratory-grade, disqualifying for anything more, and tracked as a mainnet gate. The
serve-throttle and serial-fetch caps of \S\ref{sec:sync} are identified but their fixes
are staged behind the fetch-pipelining lane. Fresh-node sync has known walls that were
each root-caused and patched (block-pack sizing, producer-key pinning, single-peer gap
trust) but the class of them argues for the snapshot-pull path as the durable answer.

\section{What would convince a skeptic}

The v0 contract, updated with results:

\begin{enumerate}[leftmargin=1.4em,itemsep=1pt]
\item A real swap settles end-to-end with the event committed to the event-log root —
\pretend{open} (DEX math and typed deltas shipped; mainnet event-root activation pending).
\item A fresh node joins via tip-proof and answers verified balance queries without ever
subscribing to the block topic, verify time $\le$10\,ms — \measured{met and exceeded}:
3\,$\mu$s live, fold-backed, zero blocks downloaded.
\item A tampered node self-halts on root divergence, exit 78, operator alarm —
\measured{mechanism live}; the staged public tamper-demo remains to be run as theater.
\item A gossiped release upgrades all running nodes with SQIsign-verified binaries and no
production pause — \measured{operational} (BLAKE3-pinned manifest auto-update in the
field since v0.20.x).
\item A user's swap-quality badge verifies in-browser against the committed root within
one frame — \pretend{open}, depends on (1).
\end{enumerate}

Two of five demonstrated, one partially, two open — stated plainly, which is exactly the
posture this project's culture demands.
