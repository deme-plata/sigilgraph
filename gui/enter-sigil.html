SIGILGRAPH

The Undeniable Chain · divergence-proof DAG

Derives your SIGIL wallet from a MetaMask signature (free, not a transaction), switches MetaMask to Polygon and adds the wrapped SIGIL token. This does not make a new wallet. The signature is deterministic, so one MetaMask account maps to exactly ONE SIGIL wallet — pressing this again, in a new tab or a private window, re-opens the SAME wallet with the SAME balance. MetaMask lives in the browser extension, not in the page, so private browsing does not change the result. For a genuinely new, empty wallet use ✨ Create New Wallet above.
